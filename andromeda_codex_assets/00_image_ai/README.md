# 00_image_ai — Pasta de envio para IA de Imagem

Jogue tudo que a IA precisa aqui. Quando o resultado voltar bom, mova para a pasta final (`01_`–`05_`) já renomeado no padrão `guidelines.md`.

## Como usar
1. `input_references/` → coloque até 3 imagens de referência (personagem, estilo, paleta).
2. `prompts/` → 1 arquivo `.md` por asset. Copie `prompts/_TEMPLATE_prompt.md`.
3. Envie para a IA: o `.md` + as referências.
4. `output_raw/` → salve o bruto da IA aqui. Só mova para `01_`–`05_` após aprovar.

## Regras rápidas
- Prompt sempre termina com `--tag [COMIC|EPIC|BLUEPRINT|LORE]` (ver `../guidelines.md`).
- Nome do prompt = nome final do asset: `model_sheets_kenua_front_v01.md`.
- Nunca edite direto em `01_`–`05_`. Tudo nasce aqui.
