# ANDRÔMEDA LIVING SIMULATION ENGINE V1.1.0

Release funcional do Living Simulation Engine integrada à Andrômeda Códex Master V2.0.1 em modo READ_ONLY.

A V1.1.0 adiciona integração causal entre domínios, comércio e preços runtime, combate MAR, mobilidade/biologia, sociedade/trabalho e composição integrada com health gates. Nenhum valor de balanceamento runtime é promovido automaticamente a cânone.

Consulte `07_RELEASE_READINESS/V1_1_0/` para metadados, validação, matriz dos 22 achados e changelog.
