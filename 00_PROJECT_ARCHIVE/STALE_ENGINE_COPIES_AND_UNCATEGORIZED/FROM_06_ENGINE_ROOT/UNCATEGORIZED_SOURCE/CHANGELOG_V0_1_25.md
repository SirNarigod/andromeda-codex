# CHANGELOG V0.1.25 DEV

## ETAPA 1 — HUD / BARRAS / STAMINA
- HUD compacto.
- Barras inimigas migradas para UI 2D projetada: horizontais, estáveis e sem rotação 3D.
- HP e Escudo atualizam o comprimento da barra em tempo real.
- Cada arma consome Stamina diferente.
- Sem Stamina suficiente, ataque é bloqueado.
- Regeneração aguarda 1.4 s após um ataque.

## ETAPA 2 — LOJAS
- Loja de Armas, Armaduras e Cosméticos separadas.
- Interagir abre catálogo; nenhuma compra automática.
- Fluxo: selecionar item -> ler atributos/preço -> COMPRAR.
- Armaduras aumentam Proteção.
- Cosméticos aumentam HP, Proteção e/ou Stamina.

## ETAPA 3 — CENÁRIO-LABORATÓRIO
- Setores: Comercial, Interações, Estande de Tiro, Predadores, Inimigos Armados, One-Shot e Alfa Final.
- Três dummies de tiro.
- Predadores distribuídos com seed fixa.
- Três inimigos ranged normais.
- Uma Sentinela One-Shot em setor marcado.
- Alfa final com HP + Escudo.
