# ARPG Stage 04 — V0.5.0

## Added
- Adaptive PRIMARY resource authority layered over CharacterCore.
- Deterministic action-cost reservations and persistent cooldown groups.
- Opt-in global cooldown support.
- Interruption/action-lock support.
- Three non-canonical placeholder consumables for system validation.
- `USE_CONSUMABLE` server-authoritative Game Core command.
- Resource snapshot exposure for the future Godot client.
- Roadmap Stage09 `GATHERING_WORK` for lore-bound mining, wood/flora/resource extraction, labor and professions for player and NPCs.

## Preserved
- CharacterCore remains the sole numeric authority for player health and PRIMARY resource pool.
- Master V2.0.1 remains READ_ONLY.
- Stage03 combat contracts remain backward compatible.
- Art pipeline remains blocked until the revised pre-art gate passes.

## Deferred
- Canonical consumable itemization: Stage05.
- Skill costs and build specialization: Stage06.
- Mining/gathering/work/professions: Stage09.
- Living NPC labor scheduling/economic feedback: Stage12.
