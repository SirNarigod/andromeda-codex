# ARPG Stage 02 — Character Core V0.3.0

Stage 02 adds deterministic, server-authoritative character progression without changing the Andrômeda canonical Master.

Implemented: six runtime core attributes, derived health/resource values, regeneration, XP and level curve, attribute-point allocation, build-evidence tracking, idempotent progression events, ALIVE/DEAD gating, Stage01-save upgrade, persistence, and client snapshot projection.

Canonical characters retain canonical identity only. Numeric character stats remain gameplay-derived unless explicitly approved as authorial data.

Deferred: combat formulas (Stage 03), equipment modifiers (Stage 05), skills/emergent-class classification (Stage 07), respawn/death resolution (Stage 13), and final art pipeline.
